**Stardust Canvas**

A premium social visual discovery platform where creators share, discover, and save inspiring visual ideas with real-time cloud sync.

---

**About**

Stardust Canvas is a modern social web application built for visual creators and idea enthusiasts. Users can upload images, engage with content through likes and comments, follow other creators, save their favorite pins, and communicate in real-time — all with a sleek, professional interface.

---

**Features**

· User Authentication – Sign up / Login with email & password
· Image Upload – Share visual ideas with title & description
· Social Feed – Discover posts from all creators in a beautiful grid layout
· Likes & Comments – Engage with content, double-tap to like
· Follow System – Follow/unfollow creators with real-time counts
· Private Messaging – Real-time one-on-one encrypted chat
· Profile Management – Edit name, bio, username & profile picture
· Saved Pins – Bookmark favorite posts to personal collection
· Premium Nitro – Unlock exclusive themes, fonts & profile frames
· Search – Find ideas, creators & content instantly
· Multi-Language – 15 languages with real-time switching
· Mobile-First – Fully responsive with native app-like feel

---

**Tech Stack**

· HTML5, CSS3, JavaScript
· Tailwind CSS
· Firebase Realtime Database
· Firebase Authentication
· Google Fonts

---

**Quick Start**

1. Configure Firebase in the <script> tag
2. Open index.html in your browser
3. Deploy to any static hosting service
